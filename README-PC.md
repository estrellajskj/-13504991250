# 水泵控制页面使用说明

更新：2026-11-09，V4。两台泵统一在同一页面，取消单泵/双泵切换。只接任意一台也能手动控制，两台都接上时共同控制；电压自动联动要求两台泵和BZY均正常。每台设备使用独立串口，无需STM32。

## 打开页面

双击 **启动控制页.bat**。保留后台窗口，关闭原水泵上位机和串口助手，避免占用COM口。端口默认8778，占用时以窗口显示的网址为准。

## 只控制水泵

只需连接要用的泵，正极或负极均可；BZY可不连接，不用选择模式。

1. 水泵正常供电，将原来能控制水泵的USB-RS485线插入电脑。
2. 在“正极泵”或“负极泵”一栏选择COM口、波特率、地址，点击对应的连接按钮。默认115200、地址1，以实际调通参数为准。
3. 等待显示“待机”。填写转速rpm、选择正转或反转，点击“启动水泵”。不需要连接BZY，也不需要流量标定。
4. 运行时修改转速，再点击“更新转速”即可。改方向前先停止水泵。
5. 点击“停止水泵”，等待确认停止后，可以点击水泵栏的“断开”。

这里直接设置转速，单位 **rpm**，不是mL/min。转速与实际出液量的关系取决于泵管和液路。

## 电压自动控制转速

1. 两台水泵按上面接好；电压自动联动要求两台泵都连接正常、均为待机。
2. 另一只USB-RS485接BZY的A/B，并插电脑；BZY单独供电。待测正负极接第1路电压输入V+/V-，不要接电流输入I+/I-，也不要把供电端与测量端混淆。
3. 在“电压采集（BZY）”栏选择它自己的COM口，默认9600、地址1，点击“连接采集”。两个独立串口的地址可以都为1。
4. 核对显示电压。已按实际购买的0～10V型号设置：展开“采集设置”，输入量程上限为10V、原始读数满量程为65535。换算为“返回值 × 10 ÷ 65535”，并用万用表比对；不要仅因ADC是12位版便改成4095。
5. 泵停止时，在“电压联动”中填写阈值和每档转速；通过“添加阈值”和行末的删除按钮调整数量，选择运行方向，点击“保存规则”。
6. 有效采集电压和泵状态均正常后，点击“启动电压联动”。

例如自己设置如下规则：

| 电压区间（上升时） | 水泵转速 |
|---|---:|
| 低于0.820V | 120rpm |
| 达到0.820V，低于0.876V | 90rpm |
| 达到0.876V，低于1.200V | 60rpm |
| 达到1.200V | 30rpm |

支持1～32个阈值，对应2～33档转速，保存后下次自动读取。阈值支持小数点后三位，例如0.82V、0.876V；转速支持两位小数。首个阈值须大于0.020V，相邻至少间隔0.021V，阈值均须小于量程上限。示例不等于客户实验参数。

电压有滤波和500ms确认时间，下降切换保留20mV回差，避免临界电压反复切换。输入三位小数不代表采集模块具备1mV的实际测量精度，需用万用表比对。

## 正负极双泵

1. 页面始终显示正极泵、负极泵和BZY三个连接栏，无需切换模式。
2. 正极泵、负极泵各自供电，各接一根USB-RS485线，分别选择不同的COM口并连接。两台泵可以使用不同的地址、波特率。
3. 手动控制只操作当前已连接的泵：只接正极泵或只接负极泵均可；两台均已连接时共同启动、改速和停止。所有已连接的泵须正常待机，不会跳过已连接但故障的泵。两台泵方向可分别设置，无需BZY。
4. 自动控制再连接BZY：两台泵加一个采集模块，共三个独立COM口。按上面保存阈值和每档转速，启动电压联动。
5. 同一电压规则计算一个目标转速，并行向两台泵下发；两台泵分别显示指令应答后的转速。只有两台都确认运行才进入运行状态；停止时两台都报告停止才确认停机。
6. 任一泵通信失败、报警、运行状态或方向异常，会对两台都请求停止并锁定故障。恢复通信并确认两台都停机、报警已解除后，才能清除故障。
7. 运行中增加或断开泵前，先停止所有已连接的泵并确认停机。物理拔线会触发故障，不会自动变成只控制剩余的一台。电压自动联动少连任一台泵时禁止启动。

两路串口并行发送，不保证物理泵在完全同一时刻动作；相同rpm也不保证两侧实际流量相同。两台泵均按M2-KK360协议控制。独立串口的设备地址可以都为1。

## 两路设备互不强制绑定

- 可以只连接水泵，也可以只连接BZY查看电压。
- 手动控制水泵期间，可以连接或断开BZY，不改变水泵的手动运行。
- 电压联动期间BZY失效或断开，两台泵保持各自最后已确认转速；重新连接且电压有效后，点击“恢复联动”，不会自行恢复。
- 自动模式需要停止后再切换手动模式、改方向或修改规则。

## 停机与异常

先停止充放电，再停止水泵，等待现场与页面确认停止后再断开设备、关闭后台。此版本没有充放电仪联锁或实际流量检测。

泵报警/通信故障会显示原因并请求停止。通信线断开时，停机命令可能送不到，物理泵可能继续运行，需要现场处理。排除故障并确认停止后点“清除故障”。

关闭网页不代表停泵；只要后台运行，自动控制继续。电脑不要休眠。后台退出/关机后无法继续控制，也不能保证物理泵自动停止。

## 模拟测试与项目文件

双击 **启动模拟测试.bat**，使用SIM-PUMP、SIM-PUMP2和SIM-BZY，页面明确标记“模拟设备”。可分别只连接SIM-PUMP或SIM-PUMP2测试手动控制，再连接另一台泵测试共同控制。模拟输入中的电压单位是mV，例如输入876代表0.876V；范围0～10000mV，可分别模拟两台泵和BZY断线。

真实与模拟配置分别在 `output/pc-control/config.json`、`output/pc-control-sim/config.json`。保存规则后下次启动读取，但不会自动连接或启动泵。兼容旧版两个阈值、三个转速的配置，保存后采用pump-pc-v2格式；旧流量参数不会作为rpm使用。升级前先确认停泵并退出旧后台，新版不会复用旧版后台。

标定、流量估算、趋势、CSV下载、配置导入导出、BZY写参数等入口已从页面移除。后台原有的记录文件和兼容协议保留，不影响新页面独立连接与直接转速控制。

换电脑时，安装Python 3.10或更新版，在项目目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-pc.txt
```

## 发给其他人使用

发送 `output/release/水泵控制-Windows-x64-V4.zip` 整个压缩包。对方使用Windows 10/11 64位，解压到桌面等有写入权限的目录，双击其中的“启动控制页.bat”或 `PumpControl.exe`，浏览器会打开控制页面，不需要安装Python。不要只发送HTML文件，也不要发送本机的127.0.0.1网址。升级前先停泵、退出旧后台，避免两个版本占用同一个COM口。

接收方的USB-RS485转换器仍需被Windows识别为COM口；驱动按实际芯片型号安装。单泵手动插一个USB即可，双泵手动需要两个，双泵电压联动需要三个。换电脑重新选择COM口，并核对设备通信参数。

发行包不会带走本机的配置和历史记录。对方保存的规则和记录在EXE旁新建的 `output` 中。原项目的 `.venv` 不能作为换电脑安装包使用。

修改程序后重新生成发行包：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe build_pc_release.py
```
